Tutorial de 5 minutos

No app, clique em Tutorial na tela para um guia que destaca cada área. Os cinco passos abaixo são a versão ilustrada, com capturas.

Abrir o tutorial completo
  1. 1 min Abra o evento Exemplo, projeto salvo ou evento novo.
  2. 2 min Confira o cadastro Igrejas e provas. No oficial, só conferir.
  3. 3 min Lance a participação Inscrição, pontualidade, uniforme e extra.
  4. 4 min Lance o pódio Ouro, prata e bronze em cada prova.
  5. 5 min Ranking e backup Classificação, exportar projeto e projetor.

O que cada aba faz

  • Início Resumo do evento e atalhos.
  • Configuração Igrejas, provas e pesos. No evento oficial já vem pronta.
  • Participação Pontos de cada igreja no dia.
  • Pódio por prova Medalhas. É o que entra no ranking.
  • Prova escrita Acertos individuais. Não muda a classificação.
  • Classificação Ranking automático com desempate.
  • Relatórios PDF de divulgação ou arquivo oficial.

Glossário essencial

MR / ER
Temas visuais (Mocidade Regular / Encontro Real). Só mudam as cores; os pesos e medalhas vêm do JSON do evento.
Desempate
Contagem de ouro → contagem de prata → pontos em provas-chave (CG Bíblia, Debate, CG Organização) → nome da igreja.
Projeto / evento
.projeto.json = configuração + dados; .evento.json = só configuração (exportável pelo menu Mais).
